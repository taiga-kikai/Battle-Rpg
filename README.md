# Battle-Rpg
# 迷宮脱出RPG

Javaで開発したターン制のダンジョンRPGです。

プレイヤーは4種類の職業から1つを選択し、ランダムに生成される迷宮を探索します。
敵との戦闘や宝箱、ショップ、装備、レベルアップなどを通してキャラクターを強化し、
3階層の迷宮を攻略して最終ボスの討伐を目指します。

## 概要

本作品では、Javaの基本的なプログラミング技術を活用して、
ダンジョン探索型のターン制RPGを開発しました。

単純な固定マップではなく、毎回異なる迷宮を生成できるようにし、
さらにスタート地点から階段やボスまで到達できるかを自動的に検証する仕組みを実装しています。

## 主な機能

- 4種類の職業からキャラクターを選択
- 3階層のダンジョン探索
- ランダムな迷路生成
- 宝箱によるアイテム・装備・ゴールドの獲得
- ランダムエンカウントによる敵との戦闘
- ターン制バトル
- レベルアップシステム
- 武器・防具の装備
- ショップでのアイテム・装備購入
- ポーションによるHP回復
- 最終ボスとの戦闘
- ゲームクリア・ゲームオーバー判定

## 職業

### 戦士

- 高いHPと防御力
- 一定確率で「会心の一撃」が発生
- 攻撃力を重視した職業

### 魔法使い

- 高い攻撃力
- 「魔力増幅」により攻撃時のダメージが増加
- HPと防御力は低め

### 盗賊

- 「二回攻撃」により通常攻撃を2回分行う
- 攻撃性能に優れた職業

### 僧侶

- 高いHPと防御力
- 戦闘中に毎ターン自動回復
- 安定した戦闘が可能

## ダンジョンシステム

ダンジョンは15×11マスで構成され、
迷路生成アルゴリズムを利用してランダムに生成されます。

マップ生成時には、

1. 迷路を生成
2. スタート地点を設定
3. 宝箱を配置
4. 階段またはボス地点を配置
5. スタート地点から目的地まで到達可能か検証

という処理を行っています。

目的地までの経路が存在しない場合はマップを再生成し、
一定回数生成しても条件を満たさない場合には固定マップを使用します。

また、シード値を利用しているため、
同じシード値を使用することで同じマップを再現できます。

## 戦闘システム

敵との戦闘では、以下の行動を選択できます。

- 攻撃
- アイテム使用
- 逃げる

敵を倒すとゴールドと経験値を獲得できます。

経験値が一定値に達するとレベルアップし、

- 最大HP
- 攻撃力
- 防御力

が上昇します。

## 装備・ショップ

ダンジョン内では宝箱から武器や防具を入手できます。

現在装備しているものより性能が高い装備を入手した場合は自動的に装備し、
性能が低い場合は売却してゴールドを獲得します。

また、階段地点やボス部屋ではショップを利用でき、

- ポーション
- メガポーション
- 武器
- 防具

を購入できます。

階層が進むにつれて、より強力な装備がショップに登場します。

## 工夫したポイント

### 1. ランダムダンジョン生成

毎回同じマップになるのではなく、シード値を利用してランダムに迷路を生成することで、
プレイするたびに異なるダンジョンを探索できるようにしました。

### 2. 到達可能性の検証

ランダム生成したマップが必ず攻略可能になるように、
スタート地点から階段やボスまで到達できるかを検証する処理を実装しました。

到達できないマップが生成された場合は再生成することで、
プレイヤーが進行不能になることを防いでいます。

### 3. 職業によるゲーム性の違い

4種類の職業ごとにステータスと特殊能力を設定し、
異なるプレイスタイルでゲームを楽しめるようにしました。

### 4. 装備によるキャラクター強化

武器や防具を入手・購入することで攻撃力や防御力を強化できるようにし、
探索・戦闘・ショップを組み合わせたゲームシステムにしました。
